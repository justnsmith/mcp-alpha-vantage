================================================================================
 Alpha Vantage MCP Server — New Tools Reference
================================================================================

Three new open-ended query tools were added to complement the existing
analyze_top_performers and get_market_summary tools. All three fetch live
market data via the Alpha Vantage GLOBAL_QUOTE endpoint, accept up to 50
symbols, and return structured JSON.

--------------------------------------------------------------------------------
1. compare_stocks
--------------------------------------------------------------------------------

Purpose
-------
Compare multiple stocks side-by-side in a single call. Rather than returning
a ranked list, it returns every requested symbol with full metrics and then
calls out four highlights automatically.

Parameters
----------
  symbols (str, required)
      Comma-separated stock ticker symbols.
      Example: "AAPL,MSFT,GOOGL,TSLA"

Response fields
---------------
  symbols            List of all symbols that were successfully fetched.
  quotes             Per-symbol metrics: current_price, previous_close,
                     change, change_percent, volume, intraday_range_percent
                     (= (high - low) / previous_close * 100).
  highest_gainer     Symbol with the largest positive change_percent today.
  biggest_loser      Symbol with the largest negative change_percent today.
  highest_volume     Symbol with the most shares traded today.
  most_volatile      Symbol with the widest intraday price range (% of
                     previous close). Useful for options traders.
  retrieved_at       UTC timestamp of the response.

Example use cases
-----------------
  - "Compare FAANG stocks right now"
  - "Which of these ETFs moved the most today: SPY, QQQ, IWM, DIA?"
  - "Show me AAPL vs TSLA side by side"

--------------------------------------------------------------------------------
2. screen_stocks
--------------------------------------------------------------------------------

Purpose
-------
Filter a watchlist down to the symbols that meet all supplied criteria. All
filter parameters are optional; omitting one means that filter is not applied.
Multiple filters are ANDed — a symbol must satisfy every supplied condition
to appear in results.

Parameters
----------
  symbols (str, required)
      Comma-separated stock ticker symbols to screen.
      Example: "AAPL,MSFT,GOOGL,TSLA,NVDA,AMD"

  direction (str, optional, default "any")
      "gainers"  — only include stocks where change > 0
      "losers"   — only include stocks where change < 0
      "any"      — no direction filter

  min_change_percent (float, optional)
      Only include stocks with change% >= this value.
      Example: 2.0 keeps only stocks up 2 % or more.

  max_change_percent (float, optional)
      Only include stocks with change% <= this value.
      Example: -1.0 keeps only stocks down 1 % or more.

  min_volume (int, optional)
      Only include stocks with volume >= this value.
      Example: 10000000 filters out thinly traded names.

Response fields
---------------
  criteria_applied   Human-readable string listing every active filter,
                     e.g. "direction=gainers, change%>=2.0, volume>=10000000".
                     "none (all symbols returned)" when no filters are set.
  matched            List of PerformerMetrics for symbols that passed all
                     filters, sorted by change_percent descending.
  matched_count      Number of symbols that passed.
  total_screened     Number of symbols for which quotes were retrieved.
  retrieved_at       UTC timestamp of the response.

Example use cases
-----------------
  - "Which of my watchlist stocks are up more than 2% today?"
  - "Show me the losers in the S&P 500 tech names with volume over 5M"
  - "Find high-volume gainers from this list: AAPL,MSFT,NVDA,AMD,INTC"

--------------------------------------------------------------------------------
3. get_portfolio_snapshot
--------------------------------------------------------------------------------

Purpose
-------
Given a list of stock positions, fetch live quotes and compute per-holding
market values, daily profit/loss in dollars, and portfolio-level totals.
Supports fractional shares.

Parameters
----------
  holdings (str, required)
      Comma-separated SYMBOL:shares pairs.
      Example: "AAPL:10,MSFT:5,GOOGL:2.5,TSLA:15"
      Rules:
        - Symbol and share count must be separated by a colon.
        - Share count must be a positive number (decimals allowed).
        - Maximum 50 distinct symbols.

Response fields
---------------
  total_market_value       Sum of (current_price * shares) across all holdings.
  total_daily_pnl          Sum of (change * shares) across all holdings.
  total_daily_pnl_percent  total_daily_pnl / prior_total_value * 100.
  holdings                 Per-position breakdown:
                             symbol, shares, current_price, market_value,
                             change, change_percent, daily_pnl
  top_contributor          Holding with the highest daily_pnl (best performer
                           by dollar impact on the portfolio today).
  top_detractor            Holding with the lowest daily_pnl (worst performer
                           by dollar impact today).
  retrieved_at             UTC timestamp of the response.

Example use cases
-----------------
  - "How is my portfolio doing today? AAPL:50,MSFT:20,NVDA:10"
  - "What's my daily P&L across these positions?"
  - "Which holding hurt me the most today?"

--------------------------------------------------------------------------------
 Shared behaviour across all three tools
--------------------------------------------------------------------------------

  - All tools return a JSON string.
  - On error (invalid input, unknown symbol, API error, rate limit), the
    response is {"error": "...", "timestamp": "..."} — no exceptions are
    raised to the caller.
  - The 50-symbol cap is enforced on every tool to stay within Alpha Vantage
    rate limits on free-tier keys (5 requests/minute).
  - Rate limit errors from Alpha Vantage are surfaced with the message
    "Rate limit reached: ..." so callers can handle them distinctly.
